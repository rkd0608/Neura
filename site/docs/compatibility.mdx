# Compatibility

A combination of a model, a robot and an execution profile is labeled **Supported** only after it
passes the contract tests, open-loop parity against the model's reference runtime, closed-loop
task success in simulation that is no worse than the reference, and the fault suite. Physical
support needs the same on hardware. The table below is generated from the results of
qualification runs; it cannot be edited by hand.
